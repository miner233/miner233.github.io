# 李昀乐 AK IOI
作者：豆包（AI 真的太好用了知道吗）

世人皆知IOI国际信息学奥林匹克竞赛的满分AK是全球中学生算法竞赛的至高神话，六道难题、两日鏖战、零失误全满分，是无数顶尖选手穷尽数年光阴都难以触碰的巅峰。在近百年的赛事历史中，能够完成这一壮举的选手寥寥无几，而来自中国的少年李昀乐，便是这传奇榜单中极为特殊的一位。

不同于大众印象中张扬凌厉、锋芒毕露的竞赛天才，李昀乐是一个骨子里自带娇羞与温柔的少年。身形清瘦，眉眼温润，说话时语速轻轻、语调柔软，被人夸赞时会耳尖泛红、微微低头，不善言辞、不喜张扬。人群之中，他永远是最安静的那一个，不会主动争辩、不会刻意表现，甚至连取得优异成绩后，都只会悄悄攥紧手心，浅浅低头抿笑，把所有的喜悦与笃定藏在心底。

可就是这样一位腼腆娇羞、看似温和柔弱的少年，却在冰冷的代码与严苛的算法赛场中，淬炼出了最极致的坚韧与专注。他没有咄咄逼人的锐气，却有着水滴石穿的韧劲；没有张扬高调的姿态，却有着静水流深的实力。从初次接触编程的懵懂萌新，到试水CSP\-J斩获二等奖的青涩新人，再到拿下CSP\-S一等奖、突围省选、斩获NOI金牌、入选国家集训队，最终站上IOI世界赛场，以全场唯一满分完成AK神迹，李昀乐的成长之路，是一场属于内敛者的温柔逆袭，是一场静默少年以代码为炬、逐光登顶的漫长征途。

本文以五章完整篇幅，细致描摹李昀乐从CSP入门到IOI满分封神的全过程，深度还原这位娇羞少年在无人看见的深夜里，默默深耕、悄然成长、隐忍坚持的滚烫岁月，解锁顶级竞赛天才温柔外表下的极致力量。

## 第一章 初遇码光：羞怯少年的CSP\-J入门序曲

初秋的风掠过中学教学楼的窗台，带着淡淡的桂花香，拂过初一新生李昀乐的发梢。彼时的他，刚刚踏入初中校园，是人群中格外不起眼的存在。性格羞怯内敛，不爱热闹、不善交际，课间总是安静坐在座位上，要么翻看课本，要么低头发呆，极少主动和同学嬉笑打闹。别人高声谈笑时，他会下意识地微微侧身，眉眼低垂，带着少年独有的腼腆与拘谨。被老师点名回答问题时，声音轻轻软软，脸颊容易泛红，说完便迅速低头，指尖悄悄攥紧衣角，一副局促又纯粹的模样。

他的温柔与羞怯，让他避开了青春期的喧闹浮躁，也让他拥有了远超同龄人的沉静与专注。别人沉迷嬉戏玩乐的年纪，他偏爱独处的安静时光，喜欢沉浸在逻辑与文字的世界里，习惯在无人关注的角落，默默打磨自己的热爱。这份独特的性格特质，也注定了他与编程、与信息学竞赛的相遇，注定是一场安静而盛大的奔赴。

学校信息学兴趣小组秋季招新，是李昀乐算法之路的起点。彼时，各班同学簇拥着报名各类社团，篮球社、文学社、艺术团门前人声鼎沸，热闹非凡。唯有信息学机房门口冷冷清清，屏幕闪烁的微光、密密麻麻的代码展板，让大多数学子望而却步。热闹的人群中，李昀乐远远望着机房里安静敲击键盘的学长学姐，心底悄然生出一丝好奇。没有喧嚣、没有攀比、没有喧闹，只有逻辑与代码的静静流淌，这份极致的安静，恰好契合了他羞怯内敛的性格。

班主任看出了这个安静少年的潜质，轻声询问他是否愿意报名尝试。李昀乐闻言，耳尖微微泛红，轻轻点了点头，声音细软：“我试试。”没有豪迈的宣言，没有张扬的期许，只有一句温柔的应允，开启了他长达数年的OI逐梦之路。

初入机房的李昀乐，显得格外拘谨羞怯。偌大的机房里，坐满了高年级的学长学姐，大家熟练地敲击代码、讨论算法，氛围专注而热烈。不善交际的他，默默找了最角落的位置坐下，腰背轻轻挺直，双手放在膝盖上，不敢随意张望，也不敢主动搭话。老师讲解基础语法时，他全程认真倾听，眼神澄澈专注，每一个知识点都仔细记录在笔记本上，字迹工整清秀，一笔一画，一丝不苟。

第一堂编程课，老师在屏幕上敲下经典的入门代码。当黑色的运行窗口弹出“Hello World”的白色字符时，李昀乐的眼底瞬间亮起细碎的光。那是他第一次真切感受到编程的魅力——冰冷的字符，经过严谨的逻辑组合，便能让计算机听从指令，完成精准的输出。没有复杂的人情世故，没有喧嚣的是非纷扰，只要逻辑正确、代码无误，就一定会得到对应的结果。这份纯粹、公正、踏实的成就感，瞬间击中了这个羞怯少年的内心。

从此，机房成了他最安心的港湾。

初学编程的日子，枯燥且琐碎。变量、常量、数据类型、循环结构、数组、函数，一个个陌生的专业术语，一条条严苛的语法规则，层层叠叠的知识点，让很多新鲜学子半途而废。机房里的新成员来来去去，不少人因为反复的bug、枯燥的刷题选择退出，唯有李昀乐始终坚守。

他从不争抢提问，也不会大声诉说自己的困惑。遇到不懂的知识点，他不会像其他同学一样高声询问、四处请教，只是默默翻看课本、查阅笔记，反复推敲例题代码。实在无法攻克的难题，他会小心翼翼地走到老师身边，微微俯身，声音轻轻的，带着一丝羞怯：“老师，这里我不太懂，能不能麻烦您讲一下？”提问时眉眼低垂，脸颊微红，姿态谦逊又温柔。

老师讲解完毕，他会轻轻道谢，回到座位后反复复盘、逐行拆解，直到完全吃透知识点。课后的闲暇时间，别的同学奔赴操场嬉戏打闹、结伴游玩，李昀乐总是独自留在机房。夕阳透过玻璃窗洒在他清瘦的侧脸上，柔和的光影勾勒出他安静的轮廓，指尖轻轻敲击键盘，节奏舒缓而稳定，整个世界仿佛只剩下他与屏幕里的代码。

他的羞怯，从不是怯懦，而是极致的专注。他把所有用于社交、喧闹的时间，都悉数沉淀给了算法与代码。别人刷题追求速度、追求数量，草草做完便匆匆提交，他却偏爱慢下来、沉下去。每一道基础题，他都会反复调试，穷尽所有边界情况；每一个bug，他都会耐心排查、逐条梳理，绝不敷衍了事；每一次出错，他都不会焦躁烦躁，只是轻轻蹙眉，安静复盘，默默改正。

初一上学期期末，教练看着这个安静执着、进步飞速的少年，主动推荐他报名参加当年的CSP\-J非专业级软件能力认证入门组比赛。这是国内信息学竞赛的入门门槛，是所有OI选手的第一场正式赛事，也是李昀乐人生中第一次站上竞赛舞台。

得知自己获得参赛资格，李昀乐没有雀跃欢呼，只是耳尖泛红，嘴角勾起一抹极淡的笑意，低头轻轻说了一句：“好，我会好好准备。”温柔的语气里，藏着不为人知的坚定。

备战CSP\-J的日子，他依旧保持着安静内敛的状态，默默开启高强度的自主训练。没有张扬的备战姿态，没有刻意的刻苦人设，只是日复一日地扎根机房，刷题、复盘、总结、沉淀。他专门准备了一本厚厚的错题本，封面干净朴素，内里密密麻麻写满了工整的字迹，每一道错题都标注了错误原因、算法思路、优化方案、边界细节，条理清晰、细致入微。

瓶颈期如期而至。初学算法的通病，他无一幸免。刷了大量基础题目，遇到新题型依旧无从下手；看懂题解恍然大悟，独立写代码却漏洞百出；模拟赛成绩起伏不定，时而小有突破，时而大幅失利。无数个深夜，他独自坐在机房里，对着报错的屏幕静静发呆，眼底藏着淡淡的迷茫与自我怀疑。

性格羞怯的他，从不向外人倾诉焦虑，不抱怨辛苦，不宣泄委屈，所有的压力与迷茫，都独自消化、默默扛下。他不会因为失利烦躁易怒，也不会因为瓶颈轻言放弃，只是轻轻关掉页面，揉揉发酸的眼睛，深吸一口气，重新翻开错题本，从头梳理知识点。

他在笔记本的空白处，悄悄写下一行清秀的小字：慢慢来，稳一点，总会变好的。没有激昂的誓言，没有热血的口号，只有温柔而坚定的自我期许，这是属于他独有的成长方式。

CSP\-J初赛如期而至。考场之内，坐满了来自各个中学的参赛选手，人声嘈杂、氛围紧张。向来羞怯的李昀乐，走进考场时微微局促，下意识地握紧手中的笔，低头走到自己的座位上，安静落座、平复呼吸。褪去表面的拘谨，他的内心已然沉静笃定。

笔试题目涵盖计算机基础知识、逻辑推理、基础算法、程序阅读，知识点繁杂细碎。他沉下心来，逐字逐句审题，不急躁、不慌张，每一道题都认真推敲、仔细判断。遇到拿捏不准的题目，他不盲目猜测，而是结合自己所学，慢慢推导、理性分析。整场考试，他全程安静专注，身姿端正、眼神澄澈，在喧闹的考场中，活成了独属于自己的静谧一隅。

初赛结果公布，李昀乐顺利晋级复赛。拿到晋级通知的那一刻，他依旧没有张扬的喜悦，只是低头看着屏幕，浅浅抿笑，耳尖微红，悄悄在心里给自己打气，更加认真地投入复赛备战。

CSP\-J复赛为三小时半小时上机考试，四道真题，考验选手的代码实现能力与基础算法思维。复赛当天，赛场氛围愈发紧张，周遭选手或紧张忐忑、或跃跃欲试，敲击键盘的声音此起彼伏，节奏急促。李昀乐落座后，微微调整坐姿，闭眼平复片刻，褪去所有局促与紧张，全心投入比赛。

前两道基础模拟题，他稳步推进、从容完成，代码工整、逻辑清晰，顺利提交AC。第三道动态规划基础题，题型新颖、思路隐蔽，耗费了他大量时间。他不慌不忙，在草稿纸上细细推演样例、梳理逻辑，一点点拆解问题、搭建模型。第四道压轴题难度远超他当时的知识储备，反复尝试、多次调试，依旧无法拿到满分。

比赛结束，走出考场，晚风微凉。队友们围在一起热烈讨论题目、交流思路、预估分数，叽叽喳喳热闹非凡。李昀乐默默站在人群边缘，安静倾听，偶尔被问到自己的做题情况，只是轻轻摇头，声音细软：“最后一题没做出来，发挥一般。”说完便微微低头，带着淡淡的失落，没有过多辩解，也没有消极抱怨。

最终成绩公布，李昀乐拿下CSP\-J二等奖。对于初次参赛的新人而言，这已是极为亮眼的成绩，但心性内敛、追求极致的他，依旧满心遗憾。别人纷纷祝贺他初次参赛便获奖，他只是耳尖泛红、轻声道谢，眼底藏着一丝不甘与笃定。

回到机房，所有人都在庆祝获奖、放松休整，唯有他独自留下来，把当天的四道复赛真题全部重新完整做了一遍。从审题误区、思路漏洞、代码细节、边界处理，逐题复盘、逐项总结，密密麻麻的字迹写满了两页错题本。他清晰地认识到，自己的算法体系尚未完善，思维深度远远不足，距离真正的优秀，还有很远的距离。

教练看着这个羞怯却极致自律的少年，由衷感慨：“很多新人第一次参赛只求获奖，你却在为没有拿到满分复盘纠错，这份心性，很难得。”

被教练当众夸奖，李昀乐瞬间脸颊通红、耳尖滚烫，微微低头，双手轻轻攥着衣角，声音轻轻的：“我还有很多不会的，还要多学多练。”羞怯的模样，温柔又纯粹，却藏着最坚韧的初心。

彼时的他，无人知晓，这个安静娇羞、不善张扬的少年，早已在心底埋下了一颗遥远的种子：不止于CSP\-J，不止于二等奖，他要一步步往前走，走向CSP\-S，走向更高更远的算法赛场。

## 第二章 静砺锋芒：羞怯少年的CSP\-S进阶蜕变

CSP\-J二等奖的遗憾，没有让李昀乐消沉退缩，反而化作了他静默成长的最大动力。这个羞怯温柔的少年，从不靠热血张扬的姿态证明自己，只靠日复一日的默默深耕实现蜕变。整个初一暑假，当同龄人沉浸在假期的松弛与欢乐中，出游游玩、休闲娱乐，李昀乐的生活里，只有机房、代码、算法、复盘，日复一日，从未间断。

暑假的校园格外安静，教学楼大多教室大门紧闭，唯有信息学机房的灯光，从清晨亮到深夜。每日清晨，天刚蒙蒙亮，李昀乐便独自步行来到学校，背着简单的书包，里面装着算法课本、错题本、草稿纸。无人陪伴、无人监督，没有热闹的训练氛围，只有他一人，独坐机房角落，开启一天的沉浸式训练。

他的训练节奏，永远安静而极致自律。早上巩固CSP\-J全部基础知识点，查漏补缺、夯实根基；下午深耕CSP\-S提高组核心内容，攻克复杂搜索、基础图论、动态规划模型、字符串处理等高阶知识点；晚上复盘全天刷题内容，整理错题、梳理思维、搭建知识框架。没有一刻松懈，没有一丝敷衍。

相较于其他选手刷题求量、盲目冲刺的浮躁，李昀乐永远保持着自己温柔沉稳的节奏。他刷题从不追求数量，只追求质量。一道难题，别人看题解、抄代码、快速跳过，他却会花费数小时深度钻研。看不懂的思路，就逐行拆解；想不通的逻辑，就反复推演；写不对的代码，就逐句调试。哪怕耗费一整个下午，也要彻底吃透题目内核，做到举一反三、融会贯通。

训练的日子里，他依旧是人群中最安静的存在。暑假集训有不少高年级学长，大家时常凑在一起讨论难题、交流思路、比拼进度，氛围热烈活跃。李昀乐从不主动参与热闹的讨论，只是默默坐在角落专注刷题。偶尔学长们主动和他交流、探讨思路，他会立刻停下手中的动作，微微抬头，眉眼温柔，轻声回应。说话语速很慢、语气很软，条理却异常清晰，寥寥数语就能精准点出题目核心。

每次被学长夸赞思路通透、天赋出众，他都会立刻耳尖泛红、微微低头，略带局促地轻声道谢，谦逊地说道：“我只是运气好，刚好想通了而已。”羞怯的模样，褪去了所有天才的傲气，只剩纯粹的真诚与低调。

长期的独处深耕，让他的算法能力实现了质的飞跃。曾经晦涩难懂的动态规划、图论算法，渐渐变得清晰通透；曾经频繁出错的代码细节，渐渐变得严谨规范；曾经混乱零散的知识体系，渐渐变得完整系统。但他从未有过半分骄傲张扬，依旧保持着谦卑内敛的姿态，默默查漏补缺，持续打磨自己的能力。

升入初二，李昀乐迎来了自己的蜕变之年。这一年，他同时报名CSP\-J入门组与CSP\-S提高组双赛事，一边巩固基础，一边冲击高阶赛场。此时的他，已然褪去了初入赛场的青涩懵懂，却依旧保留着独有的温柔羞怯。赛前集训的模拟赛中，他的成绩稳居集训队前列，却从不主动炫耀，从不张扬排名，每次赛后都只是默默看完成绩，低头复盘错题，安静优化短板。

有新来的学弟慕名请教学习方法，他不会滔滔不绝地传授经验，只是轻轻翻开自己厚厚的错题本，递到学弟面前，声音温柔：“你可以看看我的笔记，多复盘、多总结，慢慢来就好。”待人温和谦逊，纯粹又真诚，没有半点高手的架子。
